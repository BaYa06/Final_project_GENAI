# Istanbul Traveller Assistant

Помощник путешественника по Стамбулу: оценка цены жилья, чтение описания объявления, ответы по официальным документам с указанием источника.

## Команда

- Kholikov Baiirbek (ML и приложение)
- Muratbekov Batyi (RAG)
- Amatjanov Nurbek (NLP)

Преподаватель: Наргиза Жумалиева.

## Данные

- Inside Airbnb, Стамбул, выпуск от 25 сентября 2026
- Лицензия: CC BY 4.0
- Источник: https://insideairbnb.com/get-the-data/
- Сами данные в репозиторий не кладём.
- Цены в турецких лирах (₺), берём короткие котировки.

## Структура

- `notebooks/` — ноутбуки с анализом и обучением моделей
- `models/` — обученные модели
- `docs/` — документация и официальные документы для RAG
- `app/` — приложение Streamlit
- `data/` — локальные данные (не коммитятся)
