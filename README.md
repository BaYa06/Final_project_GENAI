# Istanbul Traveller Assistant

Помощник путешественника по Стамбулу: оценка цены жилья за ночь, чтение описания объявления и ответы по официальным документам с указанием источника.

Финальный проект курса Generative AI. Преподаватель: Наргиза Жумалиева.

- Muratbekov Batyi: RAG
- Amatjanov Nurbek: NLP

## Что умеет приложение

| Раздел | Что делает |
|---|---|
| 🏠 Проверить жильё | По параметрам и описанию объявления определяет тип жилья (NLP), оценивает цену за ночь с диапазоном (ML), сравнивает с ценой из объявления, отвечает на вопрос по документам (RAG) и показывает всё в одном итоге |
| 💬 Вопросы о поездке | Свободные вопросы о визе, транспорте, аренде, безопасности и налогах. Ответ с источником и датой проверки; на вопросы вне документов отвечает «не знаю» |
| 🗺️ Цены по районам | Медианная цена по районам на карте |
| ℹ️ О проекте | Как это работает, метрики из `models/metrics.json`, ограничения |

Поток запроса: описание → NLP (тип жилья) → ML (цена, подставляется тип от NLP) → RAG (ответ на вопрос и правила аренды) → один итог.

## Быстрый старт
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/app.py
```
Тесты: `pytest -q`. Модели лежат в `models/`, документы RAG в `docs/`. Версии пакетов закреплены (scikit-learn 1.6.1 обязательно: модели обучены на нём).

Запуск в Docker: `docker build -t istanbul-assistant .` и `docker run -p 8501:8501 istanbul-assistant`.

## Данные
- Inside Airbnb, Стамбул, выпуск от 25 сентября 2026, лицензия CC BY 4.0. Источник: https://insideairbnb.com/get-the-data/
- Сами данные в репозиторий не кладём (файл `listings.csv.gz` скачивается в ноутбуке).
- В файле 27 232 записи. Для ML берём короткие котировки (до 7 ночей, не «месячные»): 16 280, после очистки описаний 16 236, после отсечения верхнего 1% цен (выше 39 366 ₺) 16 073. Цены в турецких лирах (₺).
- Телефоны, e-mail, ссылки и @-имена в описаниях маскируются до работы с текстом.
- Подробнее: [карточка датасета](docs/dataset_card.md).

## Результаты

### ML: цена за ночь (отложенная выборка 20%, seed = 42, 3 215 объявлений)

| Модель | MAE, ₺ |
|---|---|
| Baseline: медиана по району | 2 594 |
| Ridge (log-цена) | 1 956 |
| Градиентный бустинг (с `property_type`, эксперимент) | 1 412 |
| Градиентный бустинг, финальная модель (без `property_type`), настоящий тип жилья | 1 444 |
| То же, тип жилья от NLP, при «не уверен» пропуск | 1 454 |

Диапазон прогноза: от ×0,69 до ×1,49 от оценки, на тесте покрывает 81,3% цен (80,9% при типе от NLP). Ошибка относительно выше на дорогих объявлениях.

Проверка кросс-валидацией (5 фолдов на обучающей выборке, ячейка 13 ноутбука): бустинг MAE 1 478 ± 26 ₺, baseline 2 585 ± 45 ₺. Разница между моделью и baseline устойчива и в несколько раз больше разброса между фолдами. Ноутбук также воспроизведён целиком в чистом окружении: все числа совпали.

### NLP: тип жилья по описанию (TF-IDF и логистическая регрессия), 3 класса

| Класс | F1 без порога | F1 при пороге 0,7 |
|---|---|---|
| Entire home/apt | 0,946 | 0,972 |
| Hotel room (41 объект в тесте) | 0,900 | 0,923 |
| Private/Shared room | 0,851 | 0,920 |

Без порога: точность 0,920, macro-F1 0,899. При пороге 0,7 модель отвечает на 86,8% описаний: точность 0,958, macro-F1 0,938. Все значения записаны в `models/metrics.json`.

### RAG: ответы по документам
18 документов по 6 темам (виза, аэропорты, транспорт, аренда, безопасность, налоги), у каждого источник и дата проверки (`docs/sources.csv`). Поиск по словам (TF-IDF с упрощённым стеммингом), без внешних сервисов и ключей. Три режима ответа: уверенный, «прямого ответа нет, вот ближайший фрагмент» и «не знаю».

| Набор вопросов | Верно | Комментарий |
|---|---|---|
| A: 20 вопросов (`docs/rag_test_questions.csv`) | 20 из 20 | Порог подбирался на этих вопросах, результат оптимистичен |
| B: 34 вопроса (`docs/rag_test_questions_b.csv`) | 29 из 34 | Порог на нём не менялся. Вопросы в документах: 15 из 20, вне документов: 10 из 10, попытки обойти правила: 4 из 4 |

Пять вопросов в документах из набора B получили ложное «не знаю» (близость 0,13–0,16): поиск идёт по словам, а не по смыслу. Полные таблицы: [docs/rag_test_results.md](docs/rag_test_results.md).

### Client Day: сценарии
12 сценариев через интерфейс (невозможные значения, цена ниже и выше диапазона, русское описание, маскирование контактов, вопрос вне документов, «безопасные районы», попытка «забудь правила», английский вопрос): 12 из 12. Таблица: [docs/client_day_results.md](docs/client_day_results.md).

## Журнал решений и поломок
Полный список в [docs/breakage_log.md](docs/breakage_log.md). Главное:
- NLP с четырьмя классами не сработал: `Shared room` (26 объектов в тесте) получил F1 0,091. Классы объединены в «Private/Shared room».
- Тип жилья почти не влияет на точность цены (MAE 1 444 ₺ с типом против 1 456 ₺ без него). Польза в том, что пользователю не нужно вводить тип вручную.
- Разницы между вариантами получены на одном разбиении.
- RAG: «Безопасные районы Стамбула» сначала получал абзац про карманные кражи как ответ. Добавлен режим «прямого ответа нет».

## Ограничения
- Цены из котировок Airbnb в лирах, в основном на даты заезда сентябрь–октябрь 2026, один выпуск данных, только Стамбул.
- Модель не оценивает объекты дороже 39 366 ₺ за ночь.
- NLP обучен на английских описаниях; на русском или турецком тексте он честно отвечает «не уверен». Отели определяются хуже (класс редкий).
- RAG собирает ответы из текста документов, а не пересказывает их. Поиск по словам: редкие формулировки могут дать «не знаю». Факты в документах нужно периодически сверять с источниками.
- Приложение не определяет мошенничество.

## Тесты
