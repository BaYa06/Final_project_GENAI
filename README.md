# Istanbul Traveller Assistant

Помощник путешественника по Стамбулу: оценка цены жилья за ночь, чтение описания объявления
и ответы по официальным документам с указанием источника.

Финальный проект курса Generative AI. Преподаватель: Наргиза Жумалиева.

## Команда
- Kholikov Baiirbek: ML и приложение
- Muratbekov Batyi: RAG
- Amatjanov Nurbek: NLP

## Что внутри
| Часть | Что делает | Статус |
|---|---|---|
| ML | Оценка цены за ночь (₺) по параметрам жилья, сравнение с baseline (медиана по району), диапазон «около 80% случаев» | готово (первая версия) |
| NLP | Определяет тип жилья по тексту описания, показывает уверенность, при низкой отвечает «не уверен» | готово (первая версия) |
| RAG | Ответы по 15+ документам для приезжих с источником, «не знаю» вне документов | в работе |

Интеграция: тип жилья, определённый NLP, подаётся в ML-модель цены; ответ RAG будет объединяться с оценкой цены.

## Данные
- Inside Airbnb, Стамбул, выпуск от 25 сентября 2026, лицензия CC BY 4.0. Источник: https://insideairbnb.com/get-the-data/
- Сами данные в репозиторий не кладём (файл `listings.csv.gz` скачивается в ноутбуке).
- В файле 27 232 записи. Для ML берём короткие котировки (до 7 ночей, не «месячные»): 16 280, после очистки описаний 16 236. Цены в турецких лирах (₺).
- Очистка: маскирование телефонов, e-mail, ссылок и @-имён в описаниях; исключён верхний 1% цен (выше 39 366 ₺).
- Колонки `price_quote_*` в признаки не входят (дублируют цену).

## Результаты (отложенная выборка 20%, seed = 42, 3 215 объявлений)
**Цена за ночь, MAE (медиана цены в тесте 4 500 ₺)**

| Модель | MAE, ₺ |
|---|---|
| Baseline: медиана по району | 2 594 |
| Ridge (log-цена) | 1 956 |
| Градиентный бустинг (с `property_type`, эксперимент) | 1 412 |
| Градиентный бустинг, финальная модель (без `property_type`), настоящий тип жилья | 1 444 |
| То же, тип жилья от NLP, при «не уверен» пропуск | 1 454 |

Диапазон прогноза: от ×0,69 до ×1,49 от оценки, на тесте покрывает 81,3% цен (80,9% при типе от NLP). Ошибка относительно выше на дорогих объявлениях (верхний квартиль цены).

**NLP: тип жилья по описанию (TF-IDF и логистическая регрессия), 3 класса**

| Класс | F1 без порога | F1 при пороге 0,7 |
|---|---|---|
| Entire home/apt | 0,946 | 0,972 |
| Hotel room (41 объект в тесте) | 0,900 | 0,923 |
| Private/Shared room | 0,851 | 0,920 |

Без порога: точность 0,920, macro-F1 0,899. При пороге 0,7 модель отвечает на 86,8% описаний: точность 0,958, macro-F1 0,938.

## Журнал решений и поломок
- Первая версия NLP с четырьмя классами не сработала: `Shared room` (26 объектов в тесте) получил F1 0,091. Классы `Private room` и `Shared room` объединены в «Private/Shared room», выбор сделан по валидации.
- Тип жилья почти не влияет на точность цены (MAE 1 444 ₺ с типом против 1 456 ₺ без него): тип уже угадывается по вместимости, спальням и удобствам. NLP-результат подаётся в ML, но выигрыш в точности мал; польза в том, что пользователю не нужно вводить тип вручную.
- Разные размеры разницы получены на одном разбиении, без кросс-валидации.

## Ограничения
- Цены из котировок Airbnb в лирах, в основном на даты заезда сентябрь–октябрь 2026, один выпуск данных, только Стамбул.
- Модель не оценивает объекты дороже порога 39 366 ₺ за ночь.
- NLP обучен на английских описаниях; на русском или турецком тексте он честно отвечает «не уверен».
- Приложение не определяет мошенничество.

## Структура репозитория
```
notebooks/   ноутбук Colab с данными, ML и NLP
models/      price_model.joblib, room_type_clf.joblib, metrics.json
docs/        документы для RAG (источник и дата в каждом файле)
app/         приложение Streamlit (app.py) и логика (pipeline.py)
tests/       тесты (pytest)
data/        данные не храним (только .gitkeep)
```

## Как запустить
1. Установить зависимости: `pip install -r requirements.txt` (scikit-learn закреплён на 1.6.1, как в Colab).
2. Положить файлы моделей из ноутбука в `models/`.
3. Запустить приложение: `streamlit run app/app.py`
4. Запустить тесты: `pytest`

Ноутбук запускается в Google Colab сверху вниз, seed = 42.
