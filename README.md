# BishkekHome AI

Помощник для покупателей квартир в Бишкеке: оценивает цену, читает тексты объявлений и отвечает на вопросы о покупке по документам с указанием источника.

Финальный проект курса Generative AI. Преподаватель: Наргиза Жумалиева.

## Команда
- Участник 1: ML-модель
- Участник 2: RAG-ассистент
- Участник 3: NLP и приложение

## Что внутри
Приложение из трёх связанных частей:

| Часть | Что делает |
|---|---|
| ML-модель | Предсказывает цену за м² в USD (`price_per_m2`) по параметрам квартиры |
| RAG-ассистент | Отвечает на вопросы о покупке по 15+ документам и показывает файл-источник; вне документов говорит «не знаю» |
| NLP | Читает текст объявления и определяет тип продавца (собственник или агент) и состояние квартиры |

Состояние из NLP передаётся в ML-модель, а ответы RAG можно объединять с оценкой цены.

## Данные
- Датасет: [raimbekovm/bishkek-real-estate](https://huggingface.co/datasets/raimbekovm/bishkek-real-estate) (Hugging Face), копия на Kaggle: `muraraimbekov/bishkek-real-estate-2025`
- Источник: объявления house.kg, декабрь 2025 – январь 2026
- Размер: 8 821 запись (8 472 после очистки)
- Лицензия: CC-BY-4.0, автор датасета указан
- Очистка: удалены пустые и служебные колонки, дубликаты и выбросы по цене (1–99 процентиль), номера телефонов в описаниях заменены на `[PHONE]`
- Ограничения: цены из объявлений, а не итоговых сделок; только Бишкек; один момент времени

## Результаты (тестовая выборка 20%, seed = 42)

**Цена за м² (MAE, $/м²)**

| Модель | MAE |
|---|---|
| Baseline: медиана по району | 239 |
| Ridge | 208 |
| Градиентный бустинг | 133 |

**NLP (TF-IDF + логистическая регрессия)**
- Состояние (3 группы), macro F1: 0.74 (без ремонта 0.88, евроремонт 0.76, жилое состояние 0.58)
- Тип продавца, F1 для «от собственника»: 0.52

Это первые результаты, они будут уточняться.

## Структура репозитория
```
notebooks/   ноутбук с данными, ML и NLP
models/      сохранённые модели (.joblib) и meta.json
docs/        документы для RAG (источник и дата в каждом файле)
app/         приложение на Streamlit
data/        описание данных (сами файлы не храним)
```

## Как запустить
1. Откройте ноутбук из notebooks/ в Google Colab и выполните ячейки сверху вниз (seed = 42).
2. Установите зависимости: `pip install -r requirements.txt`
3. Запуск приложения (после появления): `streamlit run app/app.py`
