# Карточка датасета: Inside Airbnb, Стамбул

## Кратко
Объявления краткосрочной аренды в Стамбуле с сайта Inside Airbnb, выпуск от 25 сентября 2026. Используются для оценки цены за ночь (ML) и определения типа жилья по описанию (NLP). Сами данные в репозиторий не кладутся, ноутбук скачивает файл по ссылке.

## Источник и лицензия
| Поле | Значение |
|---|---|
| Источник | Inside Airbnb, https://insideairbnb.com/get-the-data/ |
| Файл | `listings.csv.gz`, выпуск 2026-09-25 |
| Ссылка в ноутбуке | https://data.insideairbnb.com/turkey/marmara/istanbul/2026-09-25/data/listings.csv.gz |
| Лицензия | CC BY 4.0, источник указывается в README и в приложении |
| Охват | Только Стамбул, один выпуск |

## Размер и фильтры
| Шаг | Строк |
|---|---|
| Файл целиком | 27 232 |
| С ценой больше 0 | 24 553 |
| Короткие котировки (не «месячные», не больше 7 ночей) | 16 280 |
| После очистки описаний (убрать пустые и короче 20 символов) | 16 236 |
| После отсечения верхнего 1% цен (выше 39 366 ₺) | 16 073 |
| Обучение / тест (80/20, seed 42) | 12 858 / 3 215 |

Дубликатов `id` нет. Колонки `price_quote_*` в признаки не входят, потому что дублируют цену.

## Целевые переменные
- **ML:** `price` (цена за ночь в турецких лирах ₺), числовая. Распределение: минимум 320 ₺, 1% = 1 465 ₺, медиана 4 500 ₺, 99% = 39 366 ₺, максимум 502 353 ₺.
- **NLP:** `room_type`. В данных 4 класса: Entire home/apt — 11 598, Private room — 4 266, Hotel room — 246, Shared room — 126. В итоговой модели Private room и Shared room объединены в «Private/Shared room» (причина в журнале поломок).

## Признаки
Район (`neighbourhood_cleansed`), вместимость, число спален и ванных, рейтинг (с пометкой «нет оценок»), широта и долгота, число удобств, 15 частых удобств (бинарно), общая ванная, суперхост, тип жилья (в ML только как необязательный признак).

Пропуски: `review_scores_rating` — 3 505, `bathrooms_text` — 64, `bedrooms` — 5. Для рейтинга добавлен признак «нет оценок», остальное заполняется медианой.

## Приватность
Перед любой работой с текстом из описаний маскируются e-mail, ссылки, @-имена и телефоны. За весь файл замен: e-mail — 0, ссылок — 12, телефонов — 68, @-имён — 24. Во всех публичных файлах репозитория остаются только замаскированные тексты (в ноутбуке очищенные данные сохраняются только в Colab). Имена хозяев и отзывы не используются.

## Известные ограничения и смещения
- Цены из котировок Airbnb на конкретные даты, в основном заезд в сентябре и октябре 2026. Это не средняя цена за год.
- Дорогие объекты выше 39 366 ₺ за ночь исключены, модель их не оценивает.
- Описания почти все на английском. На русском и турецком NLP не работает.
- Классы редкие: отелей в тесте 41, объектов Shared room 26. Оценки по ним шумные.
- Данные отражают объявления, а не реальные сделки. Цена в объявлении может отличаться от цены брони.
- Один город, один выпуск. Нельзя переносить на другие города.

## Допустимое и недопустимое использование
Допустимо: учебный проект, ориентировочная оценка «справедливой цены», демонстрация ML+NLP+RAG. Недопустимо: определение мошенничества, оценка конкретных хозяев, юридические выводы, принятие финансовых решений без проверки.
